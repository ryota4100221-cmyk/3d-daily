## 何を再現したか

Alethia が売っているのは風景ではない。**検証できる数値**だ。
畑1枚から地球規模まで、同じ器械で測って、測ったという事実のほうを商品にしている。

だから今日の画面には地形が1つもモデリングされていない。存在するのは **28本の測点**だけで、
そのあいだにあるものは地面ではなく「推定」でしかない。
推定を推定として描くために、この装置は場を**2つ**持っている。

```
h(p)  形    = Σ wʰᵢ vᵢ / Σ wʰᵢ            wʰ = exp(−|p−sᵢ|² / 2σʰ²)   σʰ = 1.55
k(p)  確度  = 1 − exp(−G · Σ wᵏᵢ fᵢ)      wᵏ = exp(−|p−sᵢ|² / 2σᵏ²)   σᵏ = 0.78
                                          fᵢ = exp(−age / 0.34·period)
画面に出る高さ  y = AMP · h · k
```

## 分解した装置 — 「二重の核（two kernels）」

**σʰ > σᵏ。これがこの日の全部。**

形の推定は遠くの測点から借りていい。土地は連続だから、隣の測点の値はここでもだいたい効く。
でも「**確かだ**」と言える範囲は借りられない。1本の測点が保証できる距離は、
それが内挿に効く距離よりずっと短い。核を2つに割った瞬間、
**「よく見える地形」と「主張してよい地形」がズレて、そのズレが絵になる。**

そこから勝手に出てくるもの（1行も書いていない）:

- **測っていない所は白紙のまま**。k が低ければ刷りも等高線も乗らない。形は分かっているのに、引かない
- **土地が呼吸する**。28本がそれぞれ 8.5〜22.5 秒の自分の周期で測り直すので、
  紙のあちこちが別々の位相で盛り上がっては沈む。「検証済み」は永続の属性ではなく、
  測ってからの時間の関数でしかない
- **測点は自分の足元ごと沈む**。柱は y=0 ではなく h·k の地面から生えているので、
  鮮度が落ちた測点は自分が立っている地面を失う
- 画面のいちばん強い線は等高線ではなく **k = 0.40 の等確度線**。
  これが下のバーの `DEFENSIBLE AREA` と同じ 0.40 で、数字と絵が同じ1本の線を指している

刷りは連続階調にすると「霧」になってしまうので確度を6段に量子化した（等確度線の段）。
測り直しの波は別メッシュではなく**紙の上で焼いている**（`pulseAt()`）。起伏に沿うし、版面の外へはみ出さない。

## 何を捨てたか

- サイト全体（FV以外の全セクション・ナビ・コンテンツ・スクロール尺）
- Geist / Fragment Mono の実書体（ネットワーク越しの読み込みは落ちるので system mono で組んだ）
- 「地球」「衛星」「農地」といった具体物。**測ることの構造**だけを残した
- 入力（マウス・スクロール）。この装置は誰が見ていなくても測り続けているほうが正しい

## 今日踏んだ穴

`InstancedMesh` に `setColorAt` で色を入れ、マテリアルに `vertexColors: true` を付けたら
**インスタンスが全部まっ黒になった**。three の `color_vertex` は `USE_COLOR` が立つと
`vColor *= color` を必ず通すので、geometry に `color` 属性が無いと欠損属性の既定値 0 が
掛かって黒く潰れる（`instanceColor` は掛かる前に 0 になっている）。
対処は geometry に白で埋めた `color` 属性を持たせること。もう1つ、`instanceColor` は
`setColorAt` で初めて生成されるので、**最初のプログラムコンパイルまでに存在していないと**
`USE_INSTANCING_COLOR` が定義されず色が一切効かない。`useLayoutEffect` で先に1周させた。

最初の1枚では測り直しの波を別メッシュ（RingGeometry）で出そうとして、
消え忘れた輪が版面の外まで真っ黒な弧になって散らばった。撮って初めて分かった類の事故で、
`npm run build` は最後まで一度も文句を言わなかった。
