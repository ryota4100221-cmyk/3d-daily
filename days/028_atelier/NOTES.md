## 狙い
Curriculum #28「月次まとめ — この4週で最高の1本を選び、ポートフォリオ品質まで磨く」。

27日間で一番強かったのは Week1〜Week4 を貫く**磁器の静物**（Day003 環境光 / Day004 影と床 /
Day023 グレーディング / Day024 シーン構築）だった。ではそれを「もう一度きれいに作る」のでは

今日はその枠自体を降りる。**R3F の自動レンダリングを止め、1フレームが何をするかを全部こちらで決める。**

## 新しく入れた技法（前日までの自分から1段）

### 1. 自前のディファード的マルチパス・パイプライン（本プロジェクト初）
`useFrame(cb, 1)`（priority > 0）で R3F の自動 `gl.render` を停止し、1フレーム＝4パスに再定義した。

1. **G-buffer パス** — `scene.overrideMaterial` に自作 ShaderMaterial を差し込み、シーン全体を
   「rgb = ビュー空間法線 / a = 線形ビュー深度 ÷ far」として1枚に焼く。
   `DepthTexture` を使わず**深度をアルファに自前パック**したのは、精度と挙動を環境差なく握るため
   （Day024 は postprocessing が用意した深度を*読む*側だった。今日は**書く**側）。
   G-buffer は MSAA 禁止：解決時にシルエット越しの深度が平均され、再構成が壊れる。
2. **Beauty パス** — ライティング済みシーンを half-float RT へ（MSAA 4x、トーンマップ無し＝リニアHDRのまま）。
3. **AO パス** — 下記。
4. **Composite パス** — 画面に触る唯一のパス。

### 2. SSAO を自作（法線＋深度から）
G-buffer の深度から `uv` とビュー深度でビュー空間座標を再構成し（fov の tanHalf と aspect で
射線を作る方式・行列逆変換不要）、法線まわりの半球に14サンプル。黄金角スパイラルで方向を配り、
`uProj` で各サンプル点をスクリーンへ射影して**そこに実際に写っている深度**と比較、range check 付きで遮蔽率を出す。
28日目にして初めて「影」をライトからではなく**画面空間の幾何情報から**作った。

### 3. テンポラル・アキュムレーション（progressive refinement）
サンプル数を増やす代わりに、**カーネルの回転をピクセルハッシュ＋フレーム毎の黄金角でずらし**、
AO を2枚の RT でピンポンして前フレームへ指数ブレンド。履歴は**保存しておいたビュー深度と突き合わせ**、
一致しない画素（＝ディスオクルージョン）では捨てる。止まっているほど絵が澄んでいく＝時間を品質に変える設計。
25日間「1フレームは1フレームで完結」だったのを崩した（Day020 の ping-pong FBO は流体の*状態*、
今日は同じ絵の*品質*を貯める、という違い）。

### 4. スクリーンスペースの輪郭線（contour）
同じ G-buffer から深度の2次差分（傾き補正付き）と法線差でエッジを取り、遠景でフェードさせて
インク色を薄く乗せる。エディトリアルな線が磁器のシルエットにだけ出る monaka 的な処理。

### 5. 手描き equirect → PMREM の手続き環境マップ
128×64 の Float32 equirect を JS で1ピクセルずつ塗り（紙色のドーム＋床バウンス＋大きなキー窓＋
背後の冷たいリム）、`PMREMGenerator.fromEquirectangular` で roughness 対応の IBL に。
Day003/004 の drei `<Lightformer>` 手続きスタジオから一歩進み、**環境そのものが自分で書いたテクスチャ**。
フェッチ0・完全オフライン。

### 6. 旋盤（lathe）で作る磁器
各器は `SplineCurve` の制御点10個前後 → `LatheGeometry` の回転体。数字だけで器の輪郭を設計できるので、
「置物を作る」ではなく**プロポーションを設計する**作業になった。閉じた立体にして法線を素直に保ち、
G-buffer を汚さない。

### 7. 作品自身がパイプラインを見せる
右下の Render pass スイッチ（1–4キー / クリック）で Composite / Beauty / Normals / Occlusion を切替。
中間バッファをそのまま作品の一部として提示する。

## ハマった点（次の自分への申し送り）
- **オープニングのワイプが「フレーム数」で進んでいた**：`reveal += min(delta, 1/30) * k` は
  delta をクランプしているので、実質「必要フレーム数」を数える式になる。ヘッドレス（SwiftShader, 数fps）では
  9秒待っても reveal ≒ 0.8 のままで、**全カットが紙色に薄まった状態**で撮れていた。
  ビルドは通り、コンソールエラーも0、G-buffer も AO も正しい——というのが一番厄介な壊れ方。
  **時間で進める演出は必ず `clock.elapsedTime` 基準**にする（今回 `(t - t0) / 1.15` に修正）。
- 露出が疑わしいときは推測せず**ビューアに測らせる**：`step(1.0, beauty.r)` などの偽色露出計を
  debug モードに1回出せば「オーバーではない」と即断でき、原因の切り分けが一気に進んだ。
- カメラが常時ドリフトしていると履歴が微妙に汚れる。ブレンド係数 0.11 → 0.24 とドリフト幅の縮小で解消。
  本気でやるなら速度ベクトルによる**リプロジェクション**が要る。
