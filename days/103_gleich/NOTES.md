## キー演出を1つに絞る

「白い紙に黒い有機的な塊が1つ、その両脇に bleibt / gleich（ドイツ語で『同じままでいる』）」。

分解すると **幾何（支持関数）＋時間（ゆっくり転がる）＋入力（ドラッグ／gleich⇄ungleich）**。シェーダは位置の mix 1行だけ。

## 装置: 幅は変わらない（the width that stays the same）

- 凸体は支持関数 h(u)（法線方向 u への最遠距離）で決まる。h(u) + h(−u) が「u 方向の幅」＝ その向きで挟んだ2枚の板の間隔。
- h(u) = ½ + ε·p(u)、p は斉次3次式 → p(−u) = −p(u) なので幅は **どの向きでも厳密に 1**。強制する命令はどこにも無い。
- 表面点は H(v) = |v|·h(v/|v|) の勾配: **x(u) = u/2 + ε(∇p(u) − 2p(u)·u)**。球面グリッド（221×111）の各頂点をこの式で置くだけで、法線は u そのもの。マーチングも SDF も無い。
- p = (x³ − 3xy²) + 0.45z³ − 0.675z(x²+y²) + 0.6xyz。Y₃³ が赤道に Reuleaux 三角形を作り、z の項が三角形を傾けて対称な見え方を無くす。
- ε は凸性（接平面ヘッシアンの最小固有値 > 0、6000方向で検査）の二分法で ε_max = 0.06208、その **96%（ε = 0.05960）** を使う。最小曲率半径 0.020（ε_max ではしわが出る）。
- 上の板は「体に乗っているだけ」: 毎フレーム d = R⁻¹ŷ として 床 = −H(−d)、天板 = H(d)+H(−d)。
- 双子（ungleich）: h = ½ + 0.6ε·p + δ·q、q は偶の2次式。δ も凸性の二分法で δ_max = 0.1106 の 70%（δ = 0.0774）。位置は (ε, δ) に線形なので、2つの体の頂点の lerp が厳密に中間の体になり、法線は両方とも u のまま。

## 何を捨てたか

- 再現元の「黒い有機的なシルエット」の実際の形と動き（未閲覧）。定幅体に置き換えた。

## 正直に

- 「定幅」は分かっても「球ではない」は1枚の静止画では伝わりにくい。転がると輪郭が三角おにぎり→卵→丸と変わり続けるのが主役なので、動かして見る前提。
- 体積比 0.944 は Meissner（約0.80）よりずっと球に近い。滑らかさと凸性の範囲ではここまで。
