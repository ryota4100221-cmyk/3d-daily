# Day 096 — One Line Holds a Face

## 何を再現し、何を捨てたか

- **再現した**: FV の「青ベタの地に、白い一筆書きの線で人の横顔」。分解すると **幾何（1本のパス）＋シェーダ（1回のテクスチャ参照）＋入力（光）**。
- **捨てた**: 実際の線画の筆致（輪郭線をなぞる一筆書き）・人物の同定・写真・和文コピー・インターンシップ等のナビ・コーラルの差し色・スクロール。
- 一筆書きの「輪郭をなぞる線」はそのまま作らず、**プロッタの squiggle 画法**に置き換えた：線は輪郭を知らず、行の上を往復するだけ。顔は陰影の振幅としてだけ現れる。だから光を動かすと、同じ1本の線のまま顔の読め方が変わる。

## 装置：一本の線が持つ顔（one line holds a face）

1. `rig.js buildStroke` — 96行×1,700サンプル＋半円の折り返しで **1本の折れ線**（163,187頂点・静止長 96.6k px）。各頂点は自分と隣の基点・±の側・「行か折り返しか」だけを持つ。
2. `rig.js toneFrag` — 見えない頭部：楕円体・丸め円錐・カプセル14個の smooth-min（頭蓋・顔・顎・鼻・唇・眉弓・眼窩・耳・首・肩）。正投影で 90 ステップのレイマーチ、Lambert×ソフトシャドウ（鼻が頬に影を落とす）を tone = floor + (1−floor)(1−λ)^1.3 に。輪郭のための rim を少しだけ足す。
3. `rig.js strokeVert` — 頂点ごとに tone を引き、`y += 0.47·ROW_GAP · tone · sin(x·2π/5.2px + phase)`。隣の点も同じく変位させて接線を取り、そこから線幅 1.15 px の帯を張る。折り返しは変位させない。
4. ポインタ x → 光の方位（±137°）、y → 仰角。離すとゆっくり周回。頭は横顔から ±17° だけ首を振る。

HUD の数字はテクスチャを 0.5 秒ごとに readPixels して数えた実測（頭の面積比・平均の震え）。preview（t=0, 光 az −49° el 26°）で 頭が場の 30.3%、平均 tone 0.60。

## つまずき

1. 最初は光が正面寄りで頭全体が均一に震え、横顔がただの丸い塊になった → 既定の光を顔の側（az −0.85 rad）へ。
2. 次に顔側を照らすと日向の顔が平らな線＝背景と同じになって横顔の輪郭が消えた → 日向にも floor 0.26 の震えを残す（頭の内と外を分ける最低限の差）。
3. 頭蓋の楕円体が前に出すぎて額と鼻が同じ位置に並び、横顔に見えなかった → 頭蓋を後ろへ 0.12、顔の塊を後ろへ 0.12、鼻の根元を額の下へ。
4. HUD が「—」のまま焼き付いた → 初回のフレームで即読み出し。

## 正直に

- 頭部は手で置いた14個のプリミティブで、似顔でも実在の人物でもない。耳・眼窩は粗い。
- 一筆書き「風」ではなく、本当に1本の index 付き三角帯（ただし太さのために帯にしている）。
- 振幅だけで濃淡を出していて、周波数変調（位相の積分）はしていない。
