## 分解した装置 — 帰れない半分（the half that never comes home）

`src/rig.js` に書いてある操作は**1種類**しかない：

```
+x へ倒す = 軸 +z まわりに −90°     +z へ倒す = 軸 +x まわりに +90°
```

「どの面を上にする」「向きを選ぶ」に当たる式は一行も無い。にもかかわらず：

> **サイコロが盤の上で閉じた道を歩いて出発した升へ帰ってくると、
> 24 通りある姿勢のうち 12 通りにしかならない。**
> 残りの 12 通りは「出にくい」のではない。**出ない。**

証明は一行で終わる。
閉じた道は `+x` と `−x` が同数、`+z` と `−z` が同数だから、**倒す回数は必ず偶数**。
そして倒す操作は1回ごとにサイコロの**4本の体対角線を奇置換**する
（`TIP_IS_ODD` が4方向すべてについてこれを実際に確かめている）。
偶数回の奇置換は偶置換。だからサイコロは自分の回転群 24 個のうち、
**偶置換側＝正四面体群 A4 の 12 個**から出られない。

盤の広さにも、道の長さにも、囲んだ面積にも、道が自分と何回交差するかにも依らない。
効いているのは**歩数の偶奇ひとつだけ**。

### 数えてから描いた

`census(20000)` を描画より先に回している。画面に出ている数字はその出力そのもの：

```
閉路 20,000 本 / 倒した回数 304,470 回
帰ってきた姿勢 12 通り  /  1度も帰ってこなかった姿勢 12 通り
到達した集合が偶置換側とちょうど一致したか  exactlyEvenHalf: true
帰着回数（姿勢 01〜24 の順）
  1619, 0, 0, 0, 0, 2070, 1594, 1807, 1648, 1546, 1586, 1945,
  1327, 1460, 1747, 0, 0, 0, 0, 0, 0, 0, 0, 1651
```

**0 が 12 個並ぶ。**「まれ」ではなく 0。ここが今日の絵の全部。

### 書いていないのに出てきたもの

レールの 24 枠は **単位姿勢から最短何手で行けるか（`DEPTH`）の順**に並べてある。
並べ替えの規則はそれだけで、塗り／抜きの判定には一切使っていない。
それでも、こう出た：

```
手数  0   1    2    3   4
個数  1   4   10    8   1      合計 24
帰着  ○   ×    ○    ×   ○
```

**偶数手の層（1 + 10 + 1 = 12）がそのまま帰ってこられる 12 と一致し、
奇数手の層（4 + 8 = 12）がそのまま帰ってこられない 12 と一致する。**
レールに出ている縞模様は装飾ではなく、定理そのものが並んでいる。

## つまずき

1. **方位角を振ると盤が「傾いた長方形」になる。** 試作1枚目は方位角13°・仰角44°で
   組んだが、ワールドの +x が画面上で **9.1° 下がって**盤が転んで見えた。計算すると
   カメラのローカル X 軸は `(0.9743, 0, −0.2252)` で、+x の画面 y 成分が −0.156 残る。
   盤ごと13°回せば水平になるが、それはサイコロの倒れる軸も一緒に回すことなので
   立体の見えは戻らない。**盤の辺を画面の水平に一致させられるのは方位角 0 のときだけ**で、
   その代わり駒は天面と正面の2面しか見せない。隅の玉と落ち影で立体に持たせた。
2. **R3F の既定トーンマッピング（ACES）で生成りの紙が灰色になる。** 試作1枚目の盤は
   `#FDFCFB` を貼ったのに `#D5D5D5` で出た。`<Canvas flat>` で切った。切ったあとは
   逆に露出の基準が無くなるので、three r169 の物理ライト（`/π` が効く）に合わせて
   `ambient + directional×NdotL ≈ 3.4` を「紙が紙の色で出る」点として合わせている。
3. **白い駒は白い盤に消える。** 最初は駒も盤も白で、影だけが駒の証拠だった。
   主光を `(-5,17,-3.5)` ＝ **手前に倒した**位置に移して、正面の面を素の環境光だけに
   落とし（落ち影も手前・右へ出る）、天面との差で箱に見せた。
4. **`?still=N` をフレーム数で切ると仮想時間下で届かない。** `--virtual-time-budget=11500`
   の下では rAF が 60 回程度しか回らず、N=560 のつもりが frame 62 で撮れていた
   （`tips 0009`）。状態機械を `step(s, dt)` に切り出して、**マウント時に同期ループで
   N/60 秒ぶん回し切ってから止める**形に変えた。これで preview は毎回同じコマになる。
5. **空カンバスは今日も出た。** 同じビルド・同じ `budget=11500` で 74KB → 246KB、
   後半でも 90KB → 215KB。RUN.md のリトライ梯子は飾りではない。
