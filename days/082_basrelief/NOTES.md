1mm も動かない。奥行きは法線場の中にしか存在しない。

## 分解した装置

**深さは像に届かない（the depth that never reaches the image）**

正射影で真上から見た高さ場 z = f(x,y) を、アルベドと法線を1つにまとめた
`b = ρ n̂`、光の向きと強さを1つにまとめた `s` で書くと、ランバート像は内積ひとつ：

```
I(x,y) = max(0, b(x,y) · s)
```

ここで b を G⁻ᵀb に、s を Gs に置き換えると

```
(G⁻ᵀb) · (Gs) = bᵀ G⁻¹ G s = b · s
```

で、**すべての画素・すべての光源方向について同じ値**になる。G を高さ場として合法に保つ
族は3次元あり（Belhumeur, Kriegman & Yuille 1999 の generalized bas-relief）、今日はその中の
深さスケールだけを使った：

```
G = diag(1, 1, λ)  ⇒  f̄ = λf          高さは λ 倍に潰れ
                      ρ̄ = N̄/(λN)      塗りはこれだけ塗り替わり
                      s̄ = (sx, sy, λ sz)  ランプがこれだけ振れる
```

`rig.js` に「潰す」命令は無い。書いてあるのは b に G⁻ᵀ を掛け、s に G を掛けることだけで、
潰れも塗り替えもその帰結。彫刻家が浅浮き彫りで深さを偽れるのと同じ理由で、
**写真は λ を1枚も記録しない。**

上段全体の Δmax = **2.2e-16**（36,100 px を CPU float64 でサンプル）。
つまり倍精度の丸め1つぶんで、**6.9 倍の深さの違いが像に出ない。**
下段（同じ塗り・同じランプという素朴な読み）は **0.452** まで開く。
消しているのは物体ではなく、物体と一緒に動いたランプである。

## つまずき

1. **最初の被写体（小石＋さざ波）は読めなかった。** 陰影は正しいのに絵が「灰色の染み」で、
   何が潰れているのかが見えない。装置が正しくても被写体が語らなければ何も伝わらないので、
   源に合わせて瓶（胴・肩・首・キャップ・ラベルの凹み・キャップのローレット）に差し替えた。
   同じ数式・同じ2行の行列で、絵が読めるようになった。
2. **タイル座標の縦横比。** 板は 1 : 1.34 の縦長なので `uv*2-1` をそのまま渡すと瓶が縦に
   1.34 倍伸びる。`vP = (uv*2-1) * vec2(1, uAsp)` にして相似を保った。
3. **右上のリード文がいちばん右の瓶のキャップに重なった**（初回の実描画で発覚）。
   ビルドでは出ない。RUN.md の「撮った1枚は必ず目で見る」はこれのこと。2段落目を落として footer へ。
4. **有限差分でも恒等式は割れない。** f̄ = λf は線形なので FD(λf) = λ·FD(f) が浮動小数点でも厳密。
   だから ε = 0.0035 の中心差分のまま Δmax が 2.2e-16 で収まる（丸めは b·s の側だけ）。
5. 平らな縁では n̂ = (0,0,1) なので I = s_z ＝ どの λ でも同じ。**だから板に縁が出ない**——
   6枚の板は地の #606060 にそのまま溶ける。源が「地に有彩色を1つも置かない」のと同じ効き方。
