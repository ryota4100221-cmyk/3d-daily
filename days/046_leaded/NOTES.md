## 新しく入れた技法

### プリマルチプライした開口を、ピラミッドの中で一緒にフィルタする（`glass.js` / `ltc.js`）

Day 041 が「カルトンは桟を**貫いて**連続に描く」と決めたのは正しく、今日もそのままである。
理由も同じ——**トレーサリーはポリゴンが担う**（6枚のペインが形状因子の定義域で、石はそこに
入っていない）ので、テクスチャ側も石を黒くすると二重計上になる。

しかし「石を黒く塗るな」と「石を平均するな」は**別の要求**で、5日間その2つを1つのものだと
思っていた。箱フィルタは**線形**なので、開口を色の隣のチャンネルに乗せれば両方成立する：

```
level 0      rgb = L·m,        a = m          m = ペインの被覆率（厳密）
cell (m,n)   rgb = mean(L·m),  a = mean(m)    構成上、両軸とも
フェッチ      rgb / a  =  そのフットプリントの中の**ガラスだけ**の平均
```

除算1回。どのレベルでも、どのセルでも成立する。**フェッチは増えない**（Day 042 以来 RGBA を
読んでいて、A は5日間ずっと 1.0 を運んでいた）。コンポジタが30年使っているプリマルチプライド
アルファが、それが発明された仕事——**平均する集合の形が、読むレベルより細かいときの平均**
——をしているだけである。

実装は3ファイルで合計20行ほど：

- `paneCoverage(x,y,N)` ——テクセルとペイン矩形の**厳密な**重なり面積。スーパーサンプルでは
  なく解析解にした理由は、これは絵ではなく指示関数だからで、level 0 の定義が「その箱平均」
  である以上、2×2のスーパーサンプルは1テクセルにつき5値しか返せない。桟で1/4テクセルずれた
  マスクは、8段上でも1/4テクセルぶんずれる（そこでは1テクセルが窓全体である）。
- `ripCell`/`ripFetch` が `vec4` を返し、`glassMean(vec4)` が最後に1回割る。
- `glassFetch` のタップ累積を `vec4` に。**割るのはタップの後**——n個の比の平均ではなく
  比の平均でなければ、桟に落ちたスラブが根拠のない色を持ち込む。プリマルチプライは
  まさにそれを防ぐために存在する。

### 露出の基準が「読む値」に移った

`?pass=8` 以来の規則——窓全体を見る面は白を見る——は今日も保つが、**何を白に固定するかは
選択ではなく帰結**になった。フェッチが rgb を返す間は矩形平均を固定すればよかった。rgb/a を
返す今、ピラミッドの天辺が返すのは**被覆率重み平均**なので、白にすべきはそれである。
`renderCartoon` の正規化はその1つの式になり（マスク無しビルドは a=1 なので同じ式が矩形平均に
退化する）、`measurePaneMean` は「ペイン矩形をもう一度歩いてテクセルを数える」のをやめて
`sum(rgb)/sum(a)` になった。**窓の形が2箇所に書かれている状態が1つ消えた**（Day 042 が
1日払った形である）。

ついでに1つ直っていた：旧 `measurePaneMean` はペイン端を `cx/half` と**線形**で置いていたが、
フェッチの uv は窓の**平面**上（`tan`）である。0.5% のずれで、起動時に印字するだけの数字の
間は何も起こさなかった。今日それはマスクになる。

## つまずき（記録用）

**参照の単位を変換しなければ、今日は「何も起きなかった日」として印字される。**
masked ビルドは `L / paneMean` を、unmasked は `L / rectMean` を格納する。参照は unmasked の
単位で積分されているので、変換せずに masked のフェッチをぶつけると 2〜3% の系統ずれが
そのまま誤差に乗る。測ってある——`NOUNITS=1` で **4.37 が 5.71**。つまり変換を忘れていれば
今日の成果は 5.77→5.71 の 0.06 ポイントになり、**マスクのバグを探して午前が終わっていた**。
Day 042 が「`glass.js` の数と `palette.js` の数が食い違ったのを丸1日フィルタの誤差と診断した」
のと同じ種類の落とし穴を、今回は先に潰せた側。控えとして `NOUNITS` を残してある。

**マスクは解析積分にした（2×2スーパーサンプルは指示関数に対して5値しか返せない）。** 最初は
既存のカルトンと同じ 2×2 で書いていて、桟の縁が階段になった。level 0 のマスクの誤差は
box フィルタでは消えない——消えないどころか、8段上ではその誤差が窓全体のスケールで残る。

**`?pass=19` は 19 で合っていた。** Day 045 が `MODE_GAIN = 18` と書いて（0起点なので 17 が
正しい）静かに外した件を覚えていたので、今日は `MODE_COV = 18` / `?pass=19` / 上限
`PASSES.length + 9` の3箇所を先に並べて書いた。番号が3箇所にある形はまだ直っていないが、
今朝は踏んでいない。

**ヘッドレスの空カンバスは今日も2回出た**（114KB / 250KB閾値）。RUN.md のとおりリトライで
復帰。1600×1000 の正常フレームは約 1.8 MB。
