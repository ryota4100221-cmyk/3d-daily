# Day 052 — Kraft

**再現元: Mees Verberne — Creative Developer / https://meesverberne.com/**
（Notion スワイプファイルDB「深掘り済み」より。実測は「クラフト紙のベージュ #D7C6AD を地に、
市松のチェッカーを薄く透かす。文字は紺 #22264B。差し色は橙 #F7A026 を筆記体の1語にだけ」。
動きの温度は canvas/WebGL。「MEES ／ VERBERNE」を Doner Display Black の全大文字で2行、
画面幅を超えるサイズで置いて左右を切っている。）

## 何を再現したか

元サイトの FV は、ポインタを揺らすと背景の粗いピクセルが波打つ。しばらく見て気づくのは、
**動いているのは絵ではない**ということ。絵（クラフト紙に刷った粗いハーフトーン）は止まっていて、
動いているのは「そのピクセルがどの階調に落ちるか」の境界のほうだ。今日の再現対象はこの1点に絞った。

キー演出を **幾何／シェーダ／カメラ／時間／入力** に分解すると：

- **幾何**（rig.js・一度きり）— 288×180 の正方セルの格子。1セル=1インスタンス=1ピクセル。
  高さ場 `h(x,y)` は「KRAFT / HALFTONE」の文字マスク（2行を同じ幅に揃え、級数は語長の差として出す。
  版面いっぱいで左右が切れる）＋低周波の値ノイズ2オクターブ。**組んだら二度と動かさない。**
- **シェーダ**（Scene.jsx）— 3色しか無い＝階調は3段しか無い。中間色は全部 8×8 Bayer の
  秩序ディザで作る。量子化は `floor(g*2 + 0.5 + th + tide)`。橙は地(0)と紺(2)の**途中(1)にしか
  立てない**ので、結果として橙は必ず輪郭の1本になる（実測の「差し色は1語にだけ」を装置に翻訳）。
- **時間＋入力** — `tide = uAmp·sin(cell·k − t·speed) + uPush·gauss(‖cell−pointer‖)`。
  これを **`th`（しきい値）に足す**。`h` には一切足さない。だから隆起はしても波形は動かない。
- **カメラ** — 正投影＋版面を 0.34rad 倒す。遠近は付かないが、倒した分セルの側面が見え、
  紙のエンボスになる。側面は「暗くする」のではなく「1段下の色に落とす」（3色印刷の見え方。
  連続階調のライティングを足すと段の間に居場所の無い色ができる）。

## 何を捨てたか

- 元サイトの実写（青い鳥・筆記体の橙1語・バーコード・緯度経度）は捨てた。再現対象は**面の作り方**であって、コンテンツではない。
- スムーズスクロール・マーキー帯・固定ヘッダーも捨てた。FV の「格子が波打つ」1点だけに絞った。
- ポインタが無い headless では既定の隆起を地の空きに1つ置いて、装置が静止画にも写るようにした。

## 分解した装置の名前

**しきい値の潮（threshold tide）** — 絵を動かさずに絵を動かす。波は形ではなく、どの段に落ちるかに乗る。
