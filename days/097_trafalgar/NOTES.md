## 装置：魚より速い旋回（the turn that outruns the fish）

1. `rig.js step` — 群れの規則は Couzin のゾーンモデルだけ：1.0 BL 以内は反発、3.2 BL 以内は向きをそろえ、7.0 BL 以内は寄る。巡航 2.2 BL/s、旋回は 3.2 rad/s まで。水槽の壁と、群れが回り続けるためのゆるい渦がある。
2. `rig.js step（contagion）` — 足したのは1行だけ。**何もしていない魚が、2.4 BL 以内に「逃げている」仲間を見たら、75 ms 後に自分も C-start する**（見た相手から背を向け、7.0 BL/s で 0.45 s 逃げる。4 s は再び驚かない）。
3. 波はどこにも書いていない。各魚が発火した時刻 t と叩いた点からの距離 d を集めて、`d = c·t + b` を最小二乗で当てるだけ。水槽に引く黒い円はその c で描いた予測で、黒くなった魚の縁と重なれば当たり。
4. ポインタでガラスを叩く（半径 4 BL の魚を直接驚かせる）。放っておくと、静かになってから一番混んでいる場所を自動で叩く。

## 実測（node で rig.js を直接回した値・dt=1/60）

- preview（?shot=0.8：12 s 泳がせて一番混んだ場所を叩き 0.8 s 後で凍結）: **前線 23.6 BL/s＝最速の魚 7.0 BL/s の ×3.37**、到達 668/1500 匹。
- 同じ群れで3回叩いた結果: c = 22.07 / 20.67 / 7.08 BL/s、到達 1500 / 1139 / 798 匹。
  3回目は群れが薄く千切れていて、隙間を越えるには「逃げている魚が泳いで行って届く」しかないので前線が魚の速さまで落ちる。**隙間が 2.4 BL を超えると波は止まり、泳ぎで運ぶしかなくなる**＝これも装置の結果。
- 上限の目安は SEE/LATENCY = 2.4 / 0.075 = 32 BL/s。実測がそれより遅いのは、隣が真横にいるとは限らず1ホップあたりの前進が SEE より短いから。

## 正直に

- 群れ・伝染のパラメータ（SEE・LATENCY・BURST・REFRACT）は見た目と「波が魚の約3倍」になるように自分で決めた値。特定の魚種の実測ではない（ニシン等の Trafalgar effect の野外観察で「前線は捕食者より速い」と言われる事実だけを借りた）。
- 視野角（背後は見えない）は入れていない。2次元。
- 1 step 約 5 ms（node）。swiftshader の headless では間に合わないので preview は ?shot= で事前に回して凍結した1枚。
