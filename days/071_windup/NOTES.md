## 分解した装置

**貯まる回転（the stored turn）**

書いたのは3つだけ。

1. **ねじりの波動方程式**を241ノードに離散化した棒
   `ρJ ∂²θ/∂t² = GJ ∂²θ/∂z² − c ∂θ/∂t`
   5インチ ドリルパイプ（127.0 / 108.6 mm、鋼）→ `J = 1.188×10⁻⁵ m⁴`、
   `GJ = 942 383 N·m²/rad`、`ρJ = 0.0933 kg·m²/m`、
   ねじり波速 `c = √(G/ρ) = 3178 m/s`（3000 m の往復に 1.89 s）。
   dz = 12.5 m、dt = 1.2 ms（CFL 限界 dz/c = 3.93 ms の下）。
2. **上端の境界条件**：`θ₀ = Ω₀·t`。制御でも PID でもなく、ただの一次式。
   **入力は完全に一定**で、そこには揺らぎが1つも無い。
3. **下端の境界条件**：速度弱化クーロン摩擦1本
   `T_b(ω) = T_s·[f + (1−f)·e^(−|ω|/ω_c)]·tanh(ω/ε)`
   （`T_s = 14 kN·m`、`f = μk/μs = 0.42`、`ω_c = 5.5 rad/s`、`ε = 0.06`）。
   BHA 慣性 118 kg·m² を最下ノードに足す。

**これだけで、ビットは2秒止まって、次に 400 rpm で回る。**
`rig.js` を全文検索しても "stick" "slip" "stall" "release" は1語も出てこない。
状態変数も無い。分岐も無い（`if` は境界の場合分けだけ）。

読み取りは**捻れ角そのもの**：パイプに縦の塗り線が1本引いてあると思って、
各深さでその線の位置 `p(z) + r·cosθ(z)·N(z) + r·sinθ(z)·B` を繋いだ1本の線を描いた。
捻れていなければ真っ直ぐな線で、7回転巻けば7周期の波になる。
**画面に出ている波の本数が、そのまま貯まっている回転数**。

そして**波の間隔が上ほど詰まっている**のが、この絵のいちばん効いているところ。
空間周波数は `|dθ/dz| = T(z)/GJ` で、`T(z)` は「ビット摩擦＋その下の泥水抵抗の総和」
だから**地表でいちばん大きい**。捻れは深いところに貯まるのではなく、
**トルクがいちばん大きいところ＝ロータリーテーブルのすぐ下**にいちばん密に貯まる。
描いたのは1本の線だけで、その事実は式から勝手に落ちてきた。

色は**局所の角速度 ω(z)/Ω₀ ひとつ**。止まっていれば #3D444F、公称なら #98A0AC、
2.8倍を超えると朱 #FE5B2A。だから解放の瞬間、**朱がビットから地表へ 3178 m/s で駆け上がる**。
色は絵の説明ではなく、絵の中で唯一の測定量。

`[ F ]` で摩擦低減ツールを入れると、**同じ棒・同じ慣性・同じ駆動・同じ積分器**のまま、

## つまずき

1. **最初は stick-slip が起きなかった。** `ω_c = 1.6 rad/s` にしていたので、
   運転速度 12.57 rad/s では `e^(−7.86) ≈ 4×10⁻⁴` ——摩擦曲線の負勾配が
   −2 N·m·s/rad しか残らず、泥水抵抗の +44 N·m·s/rad に負けて定常滑りが**安定**した。
   ビットは 120.0 rpm のまま 10 秒回り続け、絵は「ただ捻れた棒」になった。
   `ω_c` を 5.5 rad/s に上げて負勾配を −166 にした瞬間に限界周期解が立ち上がる。
   **不安定性は摩擦の深さではなく、摩擦が弱くなる速度スケールが運転点に届いているかで決まる。**
2. **陽解法が摩擦で吹く。** `tanh(ω/ε)` の ε を 0.02 にすると原点の傾きが
   700 000 N·m·s/rad ＝時定数 0.17 ms で、dt = 1.2 ms では発散する。
   最下ノードだけ**摩擦の傾きを半陰的**に扱った（負勾配側は 0 にクランプして陽のまま残す）。
   ε は 0.06 まで詰められた。副作用として「止まっている」ビットは実際には数 rpm で
   クリープしていて、これは実機の坑底計測が返す値と同じ性質。
3. **FRS を「静摩擦と動摩擦の比を1に寄せる」だけで書いたら、トルクが増えた。**
   f を 0.93 にすると定常滑りトルクが 13 kN·m まで上がって巻き上がりが 6.6 回転になる
   ——摩擦"低減"ツールなのに。`T_s` 自体を 0.55 倍する行を足して直した。
   **振動を消すことと摩擦を減らすことは別の操作で、片方だけ書くと反対の絵が出る。**
4. **静止画の位相は運任せだった。** 周期 6.6 s のうち約 4 s が停止相なので、
   headless で撮ると高い確率で「棒が止まっている絵」になる（実際、最初の3枚とも
   ビット 0.5 rpm）。初期化時に限界周期解まで空回しする秒数を `?warm=` で外に出し、
   24.6 s に置いた。**preview は「解放の途中」で撮れている。**
   （22 s ぶんの空回しは 20 s の rpm 窓を上書きするので、t=0 の DSSI も実測値。）
5. **空カンバス閾値はまた貼り直し。** 今日は地がグラデーション＋細線が数千本で
   **実描画 476〜491 KB**。3D が死ぬと 7 KB 台まで落ちる（`--disable-3d-apis` で 6,992 B を実測）。
   前日の 95 KB のままだと空を確実に通すので 380 KB に置いた。
   なお今日は budget 400 ms でも 24000 ms でも同じ 491 116 B が出た（描画が決定的）。
