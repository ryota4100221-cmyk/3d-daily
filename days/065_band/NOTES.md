# Day 065 — The Sphere Frame

再現元：**丸の内イノベーションパートナーズ株式会社**（ベンチャーキャピタル／カーボンニュートラル領域）
https://marunouchi-innovation.com/

淡い水色 `#A0C8D8`（面積 32.5%）を地にして、紺 `#003B8F`・深緑 `#005858`・
ターコイズ `#00B0A8` の帯を球状に巻いた CG を1つだけ置く FV。設計の色が 55.3%、
FV に限れば 89.87% で、**地そのものが色になっている**側のサイト。

## 何を再現したか

**「帯が球に巻きついている」という一点だけ。**

キー演出を分解すると、これは 幾何 の話だった。シェーダでもカメラでも入力でもない。
球に巻かれた帯が帯に見えるかどうかは、**帯の姿勢**——どちらが表で、どこにねじれが
入るか——で全部決まる。そして球面の上では、その姿勢に選択の余地が無い。

```
N = p            面の法線は、球の法線しかありえない
B = p × T        T に直交して、なお球面に接する向きは1つしかない
```

だから今日のコードには「帯をどっちに向けるか」を決める行が **1行も無い**。
書いてあるのは `|p| = 1` だけで、`rig.js` でそれを書いている場所は、丸め誤差を
掃除する2行（`p.normalize()` と、T から p 成分を抜く行）しかない。
**帯は自分ではねじれない。ねじっているのは球のほうである。**

装置の名前は **球面の枠（the sphere frame）**。

## 何を捨てたか

- サイト全体（会社概要・Fund・ESG・フッター）。FV の図版1つに絞った
- スクロールリビールとマーキー。再現元の「動きの温度」には両方あるが、
  今日の主役は帯の巻きなので、スクロールに紐づけると巻きが読めなくなる
- 帯の本数と長さの正確さ。再現元は静止した造形で、こちらは走らせている
  （後述）。**形の模写ではなく、姿勢を決めている拘束のほうを再現した**
- 和文。再現元は右下に游ゴシックで小さく入れているが、このシリーズは
  英文タイポで通しているので、位置と級数だけ借りた

## 走らせた理由

再現元の球は止まっている。こちらは帯の先頭を **2.55 rad/s**（大円1周 2.46 秒）で
走らせ、窓 **9.0 rad**（大円 1.43 周）ぶんだけを残して尾を消している。

止まった造形を止まったまま出すと、**帯の姿勢が「そういう形にモデリングしたから」
なのか「拘束から落ちてきたから」なのか、絵の側から区別が付かない**。走らせると
区別が付く——先頭が新しい緯度へ入るたび、帯の表裏と幅の向きが誰にも指示されずに
入れ替わっていく。装置が動いていることが見えるのが先で、完成度はその次。

中心線は微分方程式を解かずに **2回の回転**で進めている：

1. `(p, T)` を軸 `B` のまわりに `ds` 回す — 大円に沿って `ds` 進む
2. `T` を軸 `p` のまわりに `k_g·ds` 回す — 接平面の中で曲がる

こうすると誤差がどれだけ溜まっても `|p| = 1` が壊れない。球から浮いた帯は出ない。

## 表と裏（球を描かずに球を出す）

帯の裏面は「表の色を地へ 0.66 寄せた同じ色」にしてある。球のメッシュは
**1枚も描いていない**ので、向こう側の半球にいる帯は遮られずに見える。
そこが淡い色で出ることで、**球が在ることが色だけで読める**。

表裏の判定に `gl_FrontFacing` は使っていない。三角形の巻き方向を間違えると
表裏が入れ替わり、しかもそれは `npm run build` では絶対に出ない種類の事故になる。
代わりに `dot(法線, カメラ方向) > 0` で判定した。球面上ではこれがそのまま
「手前の半球か・向こうの半球か」になるので、インデックスの向きに依存しない。

## 途中でぶつかったこと

- **k_g を振りすぎると帯が「塗り」になる。** 最初の試作は `|k_g|` が 0.4〜0.9 まで
  振れていて、深緑の帯が小さな円に巻き込み、自分の上に何周も重なって面になった。
  巻きが読める範囲は `|k_g| ≲ 0.35`＝大円のすぐ隣で、そこから出ると帯はもう帯に見えない
- **面の法線をカメラへ真っ直ぐ向けた輪は斑になる。** 帯じゅうが終端線
  （`dot(N, V) = 0`）の上に乗るので、表裏が丸め誤差で決まる。30°倒して逃がした
- **1枚目のスクリーンショットが 67KB で返ってきた**（空カンバス）。バイト数の
  リトライループがそのまま効いて、`budget=13500` の2枚目で 1414KB になった
