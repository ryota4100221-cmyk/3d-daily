## 分解
- キー演出: **横縞が走る canvas の手前に置かれた、光を透かす3Dのリング**。
- 何でできているか: **シェーダ（屈折）＋入力（屈折率）**。幾何はトーラス1個だけ、カメラは固定。
- 装置の名前: **縞が止まる屈折率（where the stripes stand still）**
  - 輪の管は断面で見ると円柱レンズ。焦点 f = n r / 2(n−1)（管軸から）。
  - 壁を管軸の後ろ D = 2r に置いた。中央を通る光は壁の h(1 − D/f) に着地するので、倍率は m = 1 − D/f。
  - D = 2r を選ぶと m = 0 になるのは n = 4/3。**水の輪では、走る縞が止まる**（中央の光線が全部壁の1点に落ちる）。
  - 空気 m=+1.00（輪は縁の幽霊だけ）→ 水 m=+0.00 → クラウンガラス m=−0.37 → サファイア −0.74 → ダイヤ −1.35（逆走して速くなる）。
  - 各ダッシュは進行方向（右）の端ほど明るくしてあるので、静止画でも向きが読める。管の左右ではその明暗が反転して見える。
- rig.js は2Dの厳密トレース（入射屈折→弦→出射屈折→壁）で倍率を**測る**。式は答え合わせにだけ使う。
  - 中央の倍率（trace）: n=1.000 → +1.000 / 1.200 → +0.333 / 1.333 → +0.001 / 1.523 → −0.374 / 1.770 → −0.740 / 2.417 → −1.345（近軸式と3桁一致）
  - 静止する屈折率を二分法で求めると **1.33333**。
  - 逆走して見える管の幅: n=1.2 で既に 45%。**縁（収差の大きい光線）が先に裏返り、中央が最後に裏返る**。
- シェーダ: 表面は proxy の torus メッシュから SDF で sphere-trace して厳密な面に乗せ、R/G/B を n∓(n−1)/(2·42)（アッベ数42相当）で別々に追跡。全反射は最大4回まで反射して追う。Fresnel(Schlick) で天井のライトストリップを映す。管の中は Beer–Lambert でごく薄いシアン。
- 入力: ポインタの横位置 = 屈折率（Air 1.000 〜 Diamond 2.417 の目盛り。水の位置に静止点のマーク）。縦位置で輪がわずかに傾く。`?n=1.333` で固定可。
