# Day 117 — REVIEW

## Round 01
- 劣るところ: 位置・大きさ＝立方体が小さく（幅 ≈ 500 px vs ref 800 px）右へ寄り（中心 x ≈ 1380/2576 → ref は x 380→1180）、下端が画面の中に収まっている（ref は下端の外へ出る）。向き＝正面寄りで上の面が細い（ref は上の面が大きな楔）。質感＝縁の粒が粗くまばらで砂を撒いたよう（ref は細かい粒が密で、内側へなめらかに濃くなる）
- 直すこと: 拡大 1.25→1.9・中心を (770,640) へ・上から見下ろす角度を増やす。粒は半径を広げ、1回拾いの比率を下げて平均側を増やす

## Round 02
- 劣るところ: 色＝右の面が橙 #F5B500 寄りで濃すぎる（ref は #F6D401→#FFDF12 の黄）。原因は ShaderMaterial に入れた Color が線形に変換されたまま sRGB へ戻されずに出ていた。向き＝右の面が大きく正面寄り（ref は左の面が大きく、右の面は右下の細い面）。位置＝上端が y≈163 で ref の 254 より 90 px 高い
- 直すこと: 色は hex をそのまま vec3 で渡す。y の回転 -0.62→-0.35、x 0.62→0.55。位置を下げ、拡大を 1.75→1.6

## Round 03
- 劣るところ: 形＝立方体が正面を向いた角の丸い箱に見え、上の面の楔と右の角（ref は (1160,510) に尖る）が無い。面の明度差がほぼ消えて一枚の黄の塊に見える。質感＝拾う半径 60 px が大きすぎて輪郭が丸い霞になり、角が読めない（ref は霞の中でも6角の輪郭が読める）
- 直すこと: ref の上の面の4頂点（奥 (750,268)・左 (392,335)・手前 (738,642)・右 (1162,512)）と手前の縦の稜・左の輪郭に、回転・位置・大きさ・画角を当て込む（/tmp の小さな当て込み：XYZ 0.326/-0.847/-0.237・位置 (0.004,-1.30)・半辺 1.711・画角 27.9°・残差 ≈ 62 px²/点）。半径 60→44

## Round 04
- 劣るところ: 質感（crop-01 で上の稜を 2.5 倍に拡大）＝縁に**灰の点**が散る（FBO は既に乗算済みの色なのに c.rgb*c.a でもう一度掛けて、縁の色が暗くなっていた）。ref の縁は「黄の地に生成りの白い点が入りこむ」密なディザで幅 ≈ 60 px、自作は「生成りの地に黄の点を撒く」まばらな砂で幅 ≈ 100 px＝粒の向きが逆。形＝当て込みで6角の輪郭・右の角・上の面の楔は ref と同じ位置に来た
- 直すこと: 乗算済みのまま平均する。不透明度は「平滑な平均 a を γ で締め、画素の乱数のしきい値で 0/1 にしたもの」と a を混ぜる＝内側から点が抜けるディザ。半径 44→34

## Round 05
- 劣るところ: 色＝左の面が全体に #FFFFA0 の薄い黄（下ほど白へのグラデーションが早く飽和していた）。ref の左の面は #FFFF55〜#FFFF59 でほぼ一様、右の面は #F5D301〜#FBD800（自作 #FFDF14 はやや明るい）。質感（crop-02）＝縁の点が 2〜3 px の塊で粗く、帯の内側に明るい黄の地が無い（ref は細かい 1 px の生成りの点が黄に入り込み、縁ほど色が淡い）
- 直すこと: 左の面 #FFFF52→#FFFF5C、右の面 #F5D200→#FBD800。乱数を sin ハッシュに替えて塊を消す。ディザの比率 0.55→0.4

## Round 06
- 劣るところ: 質感（crop-03）＝sin のハッシュが斜めの縞を作り、縁の点が斜めに並ぶ。縁の帯がまだ広く（≈ 75 px）外へまばらに散る（ref は ≈ 45 px で、内側に淡い黄の帯＝半透明の画素が多い）。色＝左の面 #FFFF55・上の面 #FFF63A・右の面 #F8D600 で ref と ±5 以内になった
- 直すこと: 乱数を Hoskins の hash（sin なし）へ。半径 34→28、ディザの比率 0.4→0.3（半透明の画素を増やして淡い帯を出す）
- 許容した差: 面の色は hex ±5 以内（これ以上は合わせない）

## Round 07
- 劣るところ: 質感（crop-04）＝縞は消え、縁の帯の幅も ref に近づいた（≈ 50 px）。残りは ref の縁の内側の「淡い黄の洗い」がまだ弱い（許容範囲）。面の配置（行ごとに面を分類して比べた）＝上の面・左の面・右の面の境目は ±15 px で一致、ただ上端が ≈ 10 px 低く左上の肩が狭い。カード（crop-05）＝写真の代わりの部屋が「箱を並べた CG」に読める（ref は明るい窓・木の床・天井のスポット・画面の中の黄色・人の群れ）。リード文が2行（ref は3行）
- 直すこと: 部屋を作り直す（明るい窓・板目の床の canvas・天井とスポット・棚の本・画面の中の黄色い立方体・長机を囲む人の影）。リード文を ref と同じ3行の長さへ。立方体を 0.03 上へ
