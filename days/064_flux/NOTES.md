# Day 064 — The Frame Gradient

**再現元**: 株式会社ANDO Imagineering Group / https://www.aig-japan.jp/
（総合設計事務所／構造設計から建築設計まで。トンマナ ビビッド・ポップ、設計の色% 63.21、13色）

当該ドメインは egress 403 で開けていない。スクショの模写ではなく、
スワイプファイルDBの実測行（配色13色・アクセント配分・業種・転用ポイント）を一次情報にした再現。

## 何を再現したか

実測行が言っていることは2つしかない。

1. **業種** —「構造設計から建築設計まで」の総合設計事務所。構造を外注しない設計事務所。
2. **色の運用** — 転用ポイントに書いてある通り、
   *「地を無彩色2色に固定し、アクセントはセクションごとに1〜2色だけ担当させる多色ブランドの運用ルール」*。
   実測では地 `#1c1c1c` / `#f7f8f8` の2色に対して有彩色が11色、
   アクセント色の配分は `#403070 20.5% / #F89878 11.2% / #50B890 7.0% / #F0B838 6.3% / #005060 6.1%`。

この2つは別々の話に見えるが、1つにできる。

> **色を選ぶのをやめる。** 13色を凡例（legend）にして、力の帯域に1色ずつ担当させる。
> 何色になるかは構造を解いた結果で決まり、こちらは一度も指定しない。

「アクセントはセクションごとに1〜2色だけ担当させる」を
「1つの色は1つの力の帯域だけを担当する」に読み替えた、というのが今日の全部。

## 分解した装置 — 架構の勾配（the frame gradient）

**場は1枚しか無い。**

膜（張力 T の面）に鉛直荷重 q が載ると、たわみ φ は

```
∇²φ = −q / T
```

を満たす。これを 41×41 の格子の上で SOR（ω=1.90）で解く。境界条件は2つだけ：

- **外周は自由端**（Neumann, ∂φ/∂n = 0）。ゴースト節点を鏡像で作る＝4辺とも跳ね出し
- **柱の位置だけ φ = 0**（Dirichlet）。荷重は全部この4点に集まるしかない

そして解いた φ を**2回読む**。

| 読み方 | 出てくるもの | 画面で |
|---|---|---|
| φ そのもの | たわみ | 版面の**形** |
| ∇φ（隣り合う節点の差 ÷ h） | その部材が運んでいるせん断 | 部材の**色** |

`rig.js` には「たわんだ板の形」を作る式が1行も無い。`Scene.jsx` には「どこを暖色にするか」の
判断が1行も無い。3,280本の部材は毎フレーム `bandOf(|∇φ|)` で色を引かれているだけで、
柱に取り付く部材が `#ff5d07` になるのは、そこに力が集まっているから以外の理由がない。

### 帯の境界は「基準解の十分位」で切る

ここが実装上いちばん効いた1行。**力の絶対値で等間隔に切ると、凡例が10色あるのに2色しか画面に出ない。**
点支持の周りの数十本だけが振り切れて、残り3,200本が全部いちばん低い帯に落ちるからだ。

そこで境界を、基準解（移動荷重を版面の中央に停めた荷重ケース）の**十分位**に置いた。
基準の状態でどの色もちょうど1割ずつ受け持つので、凡例の10色が常に全部画面にいる。
荷重が動いた分だけ部材が帯をまたぐので、**色の変化がそのまま「力の移動」**になる。

### 非対称に柱を4本

対称に置くと場も対称になって「解いている」ことが絵から消える（4分割の壁紙になる）。
格子座標 (8,12) (31,9) (12,32) (33,28) に置いたので、跳ね出しの長さが4辺とも違う。

### 副産物

- **せん断ゼロの線が勝手に出る。** 柱を横切る部材列は途中で力の向きが反転するので、
  絶対値がゼロを通る＝いちばん暗い帯（`#005060`）の線が1本引かれる。描いていない
- **色は光ではない。** 有彩色は部材にしか出さないと決めたので、荷重そのものは白い輪1本。
  地（背景・床）は無彩色に固定。再現元の運用ルールがそのまま構図のルールになった
- `Residual 2.0e-5`。34 sweeps/frame では 9.9e-1 までしか落ちず、帯が毎フレーム
  ちらついて絵が砂嵐になった。**収束していないソルバは「ノイズ」ではなく「別の絵」を出す**

## 実装で踏んだ穴（2つとも実描画でしか出ない）

1. **部材が 0.5px になる。** `BoxGeometry(1, DEPTH, WID)` を作った上で
   `scale.set(len, DEPTH, WID)` すると寸法が二重にかかる（0.082² = 0.0067）。
   ビルドは通り、PNGも620KB出て、色も出ている——ただ部材が細すぎて地が勝つ。
   直し方は単位立方体1つを使い回して寸法を全部 scale に持たせる
2. **カメラに 45° のロールが入る。** 真上に近い位置から `up=(0,1,0)` のまま `lookAt` すると
   視線と up がほぼ平行になり、基底が縮退して回転が不定になる。`camera.up.set(0,0,-1)`
   に倒して平面図の向きに固定した
