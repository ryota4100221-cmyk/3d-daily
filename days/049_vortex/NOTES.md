## 何を再現したか — キー演出を1つに絞る

**「白地に、渦が1つだけある」** これだけ。それが何でできているかを言葉にすると：

- **幾何ではない**（形は粒と線だけ）
- **シェーダでもない**（今日はGLSLを1行も書いていない）
- **時間**でできている。速度場と、その軌跡

そして渦らしさは「回っていること」からは出ない。**接線速度が折り返すこと**から出る。

```
Lamb–Oseen:  vθ(r) = (Γ / 2πr) · (1 − exp(−r²/rc²))

  r ≪ rc  →  vθ ∝ r      剛体回転。芯の中は模様が動かない
  r ＝ rc →  vθ が最大    尾がいちばん伸びる輪
  r ≫ rc  →  vθ ∝ 1/r    差動回転。腕が巻かれるのはここ
```

**分解した装置の名前: 渦芯（vortex spine）。**
式1本（`vTheta`）と、それを見えるようにする26点の履歴。この2つで渦は立つ。
`1` `2` `3` キーで rc = 0.30 / 0.62 / 1.10 を切り替えると、灰色の輪（rc）と
「尾がいちばん伸びる輪」が一致したまま太さだけ変わる。左下の vθ(r) のプロットが同時に動く。

## 作ってみて分かったこと（詰まった順）

1. **一様に撒くと渦にならない。** 差動回転は密度が一様だと見えない。回っているのに
   「放射状の雨」に見える1枚が撮れた。供給を5本の筋（arms）に分け、入口の角度を
   `armSpin` でゆっくり回したら、筋が芯へ落ちながら巻かれて螺旋になった。
   **渦は速度場ではなく、速度場に食わせる密度で見える。**
2. **循環 Γ が小さいと外周が回らない。** Lamb–Oseen は外で 1/r なので、Γ=8 では
   r=2 の粒が31秒で1周＝ほぼ静止。吸い込みだけが残って放射状になる。Γ=13.5 に上げた。
3. **headless の dt は信用できない。** 最初の撮影で「発達していない渦」が撮れた。
   `--virtual-time-budget` 下では useFrame の delta が潰れ、11.9秒撮っても
   シミュレーションが1秒も進んでいない。対処は2つ入れた：
   dt の外れ値を 1/60 に落とすガードと、生成直後に尾の張り直しを飛ばして13秒ぶん
   場だけ回す `warm()`。**初見のユーザーも育った渦から見ることになるので、両取り。**
4. **芯に詰まると団子になる。** `killR` が小さいと粒が芯に溜まって緑の塊ができ、
   渦の穴が埋まる。0.19 まで上げて早めに抜いた。
5. **rc の輪が渦の下に埋もれる。** 本文が「灰色の輪が rc」と書いているのに画面に無い、
   という状態になった。`depthTest={false}` + `renderOrder` で最後に描いた。
