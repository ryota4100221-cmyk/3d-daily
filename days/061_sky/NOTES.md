## 分解した装置 — 一次元の空（the one-dimensional sky）

金属に見えるものの正体は、反射率でも粗さでもない。**環境が1本の帯しかない**ことだ。

空を1次元に潰すと、面の色は「法線がどこを向いているか」ではなく
**反射ベクトルの仰角というスカラー1つ**で決まる。

```glsl
vec3 R = reflect(V, N);
float t = R.y * 0.5 + 0.5 + uHorizon;   // 3次元の環境が、ここで1つの数になる
vec3  c = texture2D(uBand, vec2(0.5, t)).rgb;
```

`uBand` は **256×1 px**。これが環境の全部で、光源は0個、BRDF は1行も無い。
「粗さ」は帯を ±0.0035 だけ舐める積分幅として持っているだけ。

だからこの絵の**明るい線は1本も描いていない**。帯の中の段差
（赤 #C80403 の肩と、幅0.016 の白いストリップ）に面の傾きが届いた場所に、勝手に出る。
`uHorizon` は「板が平らな所を帯のどこに置くか」という1つの数で、
これを動かすだけで同じ板が「まっ黒」から「一面の赤」まで移る（-0.54 と -0.26 で撮り比べた）。

### 傾きは高さではなく波長で稼ぐ

帯を端から端まで舐めるには法線が45°倒れる＝**傾き |∇h| が 1 に届く**必要がある。
波を高くして稼ぐと板が波打ちすぎて布ですらなくなるので、**短くして**稼いだ。
効くのは振幅 a ではなく `a·k` のほうで、今日の配分は：

```
0.299  入れ子項 sin(2.30x − 0.55t + 1.35·sin(0.62y + 0.21t))   ← 広い帯の流れ
0.062  −1.04 / 1.10
0.221   4.60 / 1.90
0.147   9.20 / −2.60
0.128  22.00 / 5.00
0.091  48.00 / −11.0                                          合計 ≈ 0.95
```

板の起伏そのものは 0.13 のまま（＝ 3.2 の高さの板に対して 4%）。

配分も効いた。**全部を同じ傾きで積むと画面が織物になり、上2項に8割寄せると煙になる。**
溶岩と織物と煙のあいだの、狭い所にしか金属は無い。今日その3つとも1回ずつ撮った。

### 法線をメッシュから作らない

`field(p)` は `vec3(h, ∂h/∂x, ∂h/∂y)` を返す。微分は有限差分ではなく閉じた式で、
入れ子の sin も連鎖律で書ける：`u = kx·x + w·t + B·sin(v)` なら `∂u/∂y = B·my·cos(v)`。

おかげで **メッシュは 220×140 しか要らない**。法線が頂点数と無関係になるので、
粗い幾何の上に細かい反射が乗る。頂点は起伏（＝上端のシルエット）を作るためだけにある。

### 地紋

「無限冒険頂点」を英語に置いた3行（INFINITE / ADVENTURE / SUMMIT）を、
袋文字（stroke のみ）で描いて 4px ぼかし、**色を持たない高さ場**として足した。
振幅 0.014。文字は読めない。読めないが、金属の帯がそこで折れる。
x方向は「1単位が W にちょうど n 個入る」ように横スケールを合わせてある
（合わせないと RepeatWrapping の継ぎ目が反射の段差として立つ）。

スクロールは板を動かさない。**地紋を横に流し（元サイトの横スクロール）、空のほうを回す**
（`uBandShift = -0.085 · scroll`）。面は一度も動かない。動くのは見えている空のほうだけ。

## 今日踏んだ穴

`npm run build` は通るのに、板が1枚も出ない真っ黒が出た。

**three は `normalMatrix` / `modelMatrix` を頂点シェーダにしか注入しない**
（`WebGLProgram` の `prefixFragment` は `viewMatrix` / `cameraPosition` / `isOrthographic` だけ）。
断片側で `normalMatrix` を書くとリンクに失敗し、エラーは console にしか出ない。
画面に出るのは「DOMオーバーレイだけが残った黒」で、これは空カンバスと見分けが付かない。
自前の `uniform mat3 uNrm` を `getNormalMatrix(mesh.matrixWorld)` で毎フレーム渡して解決。

`engine/` からは1ファイルも持ってきていない。palette.js も使っていない。
