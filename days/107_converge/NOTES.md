## 計測・式（画面には出さない）

- カメラは正投影、1 unit = 1 px（1440×900 の画面座標で置ける）
- 各片＝四面体。4頂点を ref.png から画面 px で読み、面が3枚見える片は真ん中の頂点を、2枚見える片は2枚が共有する稜線の2頂点を手前（z = 25〜120 px）へ出す。
  正面から見た輪郭は4点の凸包そのままになり、回すと奥行きが現れる
- 🔴 **面の色は光ではなく塗り分け**：最初は `k = dot(n, L)` を step で3段に写したが、Round 02 で
  1つの光源 L と閾値2つを Python で当てはめても（ランダム 6万＋山登り 20万試行）、再現元の見えている19面のうち4面が合わなかった。
  再現元は光で塗っていない＝面ごとに段を決めている。そこで頂点属性 `tone`（0 暗／1 中／2 明）を面ごとに持たせた
- 色は ShaderMaterial の最後に `#include <colorspace_fragment>` を入れて sRGB に戻す（Round 01 は線形のまま出して #006B6B 近くまで沈んだ）
- 呼吸：各片の中心を画面中心から半径方向に `r · (1 + 0.012 sin(0.4t + φ))`、3軸に ±0.04〜0.06 rad の揺れ（周期 30〜50 s）
