## 装置：輪が消える夜（the night the rings go out）

- rig.js が知っているのは3つだけ：
  1. `OBLATE` = 54,364 / 60,268 km（楕円体）
  2. `ringTau(r)` = 輪の垂直光学的厚み（C環・B環・カッシーニの間隙・A環・エンケ/キーラーの間隙・F環）。GLSL と JS で同じ表
  3. `sunElevation(year)` = 26.73°·sin(2π(year−2025.35)/29.457)
- **輪の明るさ**：単散乱スラブ
  - 照らされた面：I/F = K·μ₀/(μ₀+μ)·(1−e^{−τ(1/μ₀+1/μ)})
  - 裏面　　　　：I/F = K·μ₀/(μ−μ₀)·(e^{−τ/μ}−e^{−τ/μ₀})
  - どちらも頭に μ₀ が掛かっている。**分点 μ₀=0 で両方とも厳密に 0**。
- **輪の影（惑星の上）**：惑星の画素から太陽に向かって歩き、輪の面に着いた所の τ を読んで e^{−τ/μ₀}。
  分点では μ₀→0 で影は黒く濃くなるのに、輪の面に届く画素が赤道の1本に縮むので、**影は線になる**。
  B環外縁の影の緯度：B=26.73° で −42.82°、10° で −10.92°、2° で −2.11°、0.5° で −0.53°（≈ −B）。
- **惑星の影（輪の上）**：輪の画素から太陽方向の光線と楕円体の最近接距離で判定。
- **カメラが見る B環の平均輝度（至点=100%）** — rig.js の同じ関数で JS 実測：

| 太陽の仰角 B | 輪の光 | 輪の光 / μ₀ |
|---|---|---|
| +26.73°（至点） | 100.000% | 1.4819 |
| +18.77° | 88.294% | 1.8290 |
| +10° | 65.358% | 2.5088 |
| +5° | 41.895% | 3.2040 |
| +2° | 20.149% | 3.8484 |
| +1° | 10.801% | 4.1254 |
| +0.1° | 1.155% | 4.4112 |
| +0.01° | 0.116% | 4.4420 |
| 0°（分点） | **0.000%** | — |
| −5°（裏面） | 0.108% | — |
| −21.39°（裏面） | 3.066% | — |

  最後の列が μ₀→0 で **1/μ = 1/sin 13° = 4.4454** に収束する＝分点直前の明るさは μ₀/μ で、**τ が式から消える**。
  B環のように τ≈3 の厚い氷も、「光が寝ている」ことには勝てない。
- 裏面（太陽が南・カメラが北）では、τ≈3 の B環がいちばん暗く、薄い C環・カッシーニの間隙・A環が透けて光る
  （カッシーニ探査機の裏面写真と同じ反転）。これも式が勝手に出す。

## 正直に

- `RING_K = 0.62`（ω·P/4：粒子のアルベドと低位相角の後方散乱をまとめた露出）は**調整値**。輪の明るさの絶対値はこれで決めている。
  分点で 0 になること・μ₀ に比例して消えることは調整していない。
- 季節は正弦で近似（実際は離心率のせいで半季節が 13.7 / 15.7 年と不等）。分点は 2025.35 に合わせた。
- カメラの仰角は固定（実際の地球からの見込み角は太陽とほぼ一緒に動く）。固定したから、太陽だけが絵を変える。
- 輪の厚み（実際 ~10 m）・輪の自己影・土星照（輪に照らされる夜側）・多重散乱は無い。夜側の光は 0.2% 程度の定数。
- 輪の粒子構造は1画素より細かいので、画素の半径方向の幅で τ を8点平均している（点サンプルだとモアレが出た）。
