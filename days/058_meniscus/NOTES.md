## 分解した装置：**面張力の縁（meniscus rim）**

液体を体積として持っていない。あるのは 384² のテクスチャ1枚に載った高さ場 `h(x,z)` で、
これは「揺れる平らな円板」でしかない。器にしているのは境界条件2つだけ。

**① 壁で折り返す（`rig.js` のソルバ）**

```glsl
if (r > 0.995) {                                   // 壁の外側は
  vec2 q = (p / r) * (2.0 * 0.995 - r);            // 内側の鏡像を返す
  gl_FragColor = texture2D(uPrev, q * 0.5 + 0.5);  // = 反射する壁 = 閉じた器
  return;
}
```

波が縁で跳ね返り、戻ってきて自分と干渉する。これを外すと波は端から抜けていき、
一滴落としても輪が1本広がって終わる——「水たまり」になる。
プレビューの上半分に出ている大きな弧は、外に出られなかった波が戻ってきたもの。

**② 壁で持ち上がる（描画時に足す）**

```glsl
float meniscus(float r){ return 0.01380 * exp(-(1.0 - r) / 0.0420); }
```

高さ場には足さない（波動方程式が壊れる）。**法線を作るときだけ**足す。
これで「静かなときも縁は常に持ち上がっている／波はその上を通り過ぎる」が両立する。
縁の 1.4% ぶんの盛り上がりが法線を約 15° 倒し、そこだけ環境の別の場所を映すので、
口のきわに明るい輪が1本立つ。**この輪は描いていない。境界条件の副産物として出る。**

そのうえで、液面は光源を1つも持たない：

- 屈折 `refract(-V, N, 1/1.339)` を深さ `d(r) = 0.32(1 - r^2.2)` ぶん進めて朱漆の底に当てる
- 集光は液面の曲率 `∇²h` × 深さ。朱の上を走る明暗はこれ1本で、光源を足していない
- 反射は解析環境 `envColor()`。同じ関数を equirect に焼いて PMREM に通し、
  黒漆の外側もそれを映す（器と液体が同じ部屋を見ている）

## 今日つまずいた2つ（どちらもビルドは通る）

**1. 部屋が天地逆だった。** `DataTexture` は `flipY = false` なので row 0 は
three の `equirectUv` では `v = 0`＝**真下**。素直に上から下へ焼くと空が床に入る。
結果、盃の**底**が空を映して、黒漆が白い陶器に化けた。
`color` を疑って1時間溶かした（色は最初から `#0A0908` で正しかった）。

**2. headless の rAF はほとんど来ない。** `--virtual-time-budget=11900` の下で
`performance.now()` は 11900 まで進み `setInterval` は 743 回発火するのに、
**`requestAnimationFrame` は 45 回**（別の回は 1 回）しか来なかった。
フレーム数を時計にすると 0.75 秒ぶんしか進まず、**波が1本も立っていない水面**が焼き上がる。
`preview.png` は 169KB 出るのでバイト数では検出できない。
対策は2つ入れた：時計を実経過にして必要なサブステップぶん回す／
**最初の1フレームを描く前に 640 ステップ（5.33 秒）予熱する**。
何フレーム描けても水面は必ず生きている。
