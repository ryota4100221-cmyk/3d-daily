# Day 025 — ローディング/トランジション・Passage（R3F）

Week 4 · ★★★★★ / Composition & Polish

## 狙い
これまでの24日はすべて「1つのシーン」だった。今日のテーマは**遷移そのものの演出設計**——
ローディングからの立ち上がり、そしてシーンからシーンへ「ページをめくる」体験を作品化する。
3つの磁器の章（Origin / Assembly / Ascent）を用意し、切替でなく**演出された移行**で結ぶ。

## 新しく入れた技法（前日までの自分から1段）
- **全シーン単位のトランジション＝デュアルFBO合成**（本プロジェクト初）。
  各章を**それぞれ独立した `THREE.Scene`** に `createPortal` で流し込み、毎フレーム
  `gl.setRenderTarget(fboA/fboB)` → `gl.render(sceneFrom/To, cam)` で**2つの世界まるごとを
  別々のオフスクリーンバッファへ描画**。最後にフルスクリーンクアッドの
  トランジションシェーダで両テクスチャをクロス合成する。
  これまで（Day019ディゾルブ=面の存在/非存在、Day022-024ポスプロ=1本の色フレーム加工）は
  すべて**単一シーン内**の処理だった。今日は初めて**シーンとシーンの間**を作る。
- **方向性のあるトランジション3種を1シェーダで**：directional wipe / noise dissolve / radial iris。
  各遷移の前線 `field ≈ threshold` に沿って**テラコッタの光のシーム**が走る（`smoothstep`帯＋
  白熱コア `pow(seam,6)`）。前線には値ノイズfBmのワープをかけ有機的なエッジに。
- **演出されたローディング**：アセット依存でなく**設計されたシークエンス**。DOMのカウンタ（000→100%）
  ＋バー、完了で紙のカーテンがフェード。裏では紙のvoidから第1章へ dissolve reveal が同期して走る。
- **pointer-as-DIRECTOR**（light/force/focus/grade/sun に続く新インタラクション）：
  カーソルでシームの角度を操り、トランジション中は進行度をスクラブ（前線を押し引き）。
- `?t=<秒>` ディープリンク＝タイムラインを任意の瞬間で凍結（Day023 `?grade` の系譜。
  重いシーンで headless の virtual-time がクロックを進めきれない問題への確定的検証手段も兼ねる）。

## カラー/構図
monaka のトンマナを継続。紙(#e7e1d5)ベース、磁器はmeshPhysical（clearcoat+sheen）、
差し色はテラコッタ(#c8663a)を各章1点＋シームの光のみに絞る。章ごとに手続きPMREM環境
（canvas→PMREM、HDRIフェッチなし＝オフライン安全）の色温度を変え、Origin=中立暖、
Assembly=金色、Ascent=寒色マットへ。英語タイポ大見出し＋余白。

## 罠 / 学び
- priority>0 の `useFrame` を使うと R3F は**自動レンダーを止める**ので、2つのFBO描画後に
  `gl.render(state.scene, cam)`（クアッド）を**自分で呼ぶ**必要がある。
- クアッドはカスタム ShaderMaterial ゆえ three の**自動の色空間変換が入らない**。FBOは
  トーンマップ済みリニアを保持するので、シェーダ末尾で **sRGB OETF `pow(1/2.2)` を1回**かける。
- シームの初期値が強すぎて iris が中央で白飛び→`pow(seam,2)`＋強度0.28/コア0.3、帯幅 edge*0.95 に絞り
  「太い光の輪」から「細い光の線」へ。
- headless は重いシーンだと virtual-time でクロックがほぼ進まず（1章あたりFBO2枚＋PMREM）
  ローダが000%で凍結。`?t=` で瞬間を凍結して各章・各遷移の実描画を確認（swiftshader 6s）。

## 次に試したいこと
- FBOを保持して**前フレームのフィードバック**（残像トランジション、モーションブラー付きワイプ）。
- 遷移中に**カメラ自体を章間で飛ばす**（今は共有カメラ・被写体だけ入替）＝Day010スクロールと接続。
- ユーザー操作で章を**任意順にジャンプ**（クリックでチャプター選択→矢印UI）。
- GL-transitions のレパートリー（glitch / morph / warp）をシームのボキャブラリに追加。
