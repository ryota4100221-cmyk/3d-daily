# Day 084 — The Weight That Closes the Counter

再現元: **PP Neue Montreal（Pangram Pangram の書体スペシメン）** https://neuemontreal.com/
（スワイプファイルDB「深掘り済み=true」→ `地の明度=黒地` かつ `参考タグ ⊇ タイポグラフィ参考` を COUNT(*) で 58行 → 通読して、直近7日に一度も無い subject=文字 を取れるこの1件。DBの実測：タイポ＝「ネオグロテスクを Hairline→Black の全ウェイトで段階表示」、トンマナ＝ミニマル／エディトリアル／モノトーン、アーキタイプ根拠＝「ウェイト総覧＋実寸見出し＋本文サンプルというスペシメン構造で、書体そのものを見せている」）

## 何を再現し、何を捨てたか

- **再現した**：スペシメンのキー演出ひとつ＝**ウェイト総覧（Hairline→Black を縦に積んだ一覧）**。同じ語を太さだけ変えて段に並べ、書体そのものを被写体にする構造。
- **それは何でできているか**：幾何（と時間）。ウェイトを「デザイナーが1段ずつ描いたもの」ではなく「1本の骨格線からの距離 ≤ r の集合（ミンコフスキー和）」に置き換え、r だけを動かす。
- **捨てた**：モントリオールの写真・旅行ガイド風のコピー・多言語グリフ表・本文サンプル・スクロール尺・書体そのもの（PP Neue Montreal はライセンス書体なので使わず、骨格は円と線分だけで自作）。

## 分解した装置：カウンターが閉じる重さ（the weight that closes the counter）

- 語は **bold**。b / o / d のボウルは全部**同じ円（半径 R = 0.5、x-height = 1）**、b と d の縦線はボウルに接する。
- 各段は `ink(r) = { p : dist(p, 骨格) ≤ r }` で、段ごとに違うのは r と字間（`gap = 0.46 + 2r`。隣の字と融合する前にカウンターが閉じるよう、サイドベアリングを線幅と一緒に広げる＝実際の書体と同じ理屈）だけ。
- **o の墨は、カウンターが開いている間は厳密に 4πRr（r について一次）**。閉曲線の平行曲線は外側で πr² 増え内側で πr² 減るので、r² の項が消える。閉じた後は π(R+r)²。l（線分＋丸キャップ）は 2rh + πr² で、r² の項が残る。
- **残るカウンターは最大空円＝半径 R − r**。3つのボウルが同じ円なので、**語全体のカウンターは r = R で同時に 3 → 0 になる**。flood fill の二分探索で r* ∈ [0.49882, 0.49883]（格子 h=0.004 の半画素ぶん手前）。
- 壁（右）：11段の静的なランプ。Black は r = R/2 に置いた＝**線幅 2r とカウンター直径 2(R−r) が等しくなる点**（これは実測ではなく私の設計判断。ブラック体で「線とカウンターが同じ太さ」に近づくという経験則に合わせた）。最後の段 Past Black（r = 1.08R）だけカウンターが無い。
- 左の1語：同じ骨格が 9 秒周期で Hairline → 閉じる先 → Hairline を呼吸する。骨格線は墨の中に黒い髪の毛として残してあり、「太さは骨格からの半径」がそのまま見える。

| Hairline | 0.0120 | 0.07530 | 0.07540 | −1.4e-3 | 3 |
| Regular | 0.0648 | 0.40753 | 0.40738 | 3.5e-4 | 3 |
| Bold | 0.1273 | 0.79990 | 0.79995 | −6.6e-5 | 3 |

| Past Black | 0.5400 | 3.39811 | 3.39795 | 4.9e-5 | 0 |

語全体の閉じたカウンター面積（flood fill）と 3π(R−r)² の差は全段で ≤ 6e-4（Black: 0.5895 vs 0.5890）。

## 正直に

- 実際の PP Neue Montreal の Black はカウンターを閉じない。本物のウェイトは1本の骨格の膨張ではなく、コントラスト（縦線と横線の太さの差）とカウンターの補正を段ごとに描き分けている。この作品は「もし太さが半径だけだったら何が起きるか」の模型で、書体の再現ではない。
- 画面上の数字の表は rig.js の閉じた式（4πRr 等）を出している。ラスタ実測との照合は verify.mjs 側。

## つまずき

1. **R − r のリング**を最初に描いたら、それは o の内側の輪郭そのものだった（最大空円＝カウンターの縁）。二重線になって意味が無いので、リングをやめてカウンターを 7% の灰で塗る方式に替えた。
2. **骨格の髪の毛**を `fwidth` 幅で描いたら、小さい段で点線状にエイリアスした。固定幅 0.0045 にして、壁の小さい段では消した（左の大きい1語だけに残す）。
3. **字間が r と一緒に広がる**ので、左の呼吸する1語が重い位相で右の壁にぶつかった。1.32 → 1.04 倍に縮めた。
4. 空カンバス：今日の閾値は 150KB（実描画 157〜212KB／空 65KB）。budget 9000 と 11000 がどちらも1回ずつ空を出したので、リトライ梯子は前日のまま。
5. 静的な基線罫が `transparent` だと重い段の墨の上に描かれた。不透明にして先に描かせた。
