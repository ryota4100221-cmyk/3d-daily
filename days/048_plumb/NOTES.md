## 今日の新しいもの

### 平面の上に書くと、核は初等関数2つの積でしかない

なぜ射線が重心でないかは1行で言える。**`f` は開口の立体角にわたる w の積分**なので、
`f/|f|` は**立体角の重心方向**である。核は立体角 × 余弦を**平面の上で**読んだもの。
平均方向が一度も運んでいない重み2つ。

窓の点は X = p1 + u·V1 + v·V2 で、uv 面積から立体角への変換は (no·X)/|X|³。そして
**`no·X` は平面上のどの点でも同じ数** dA である。だから

```
    k(u, v)  =  max(X_z, 0) · dA / |X|⁴
```

定数 × 初等因子2つ。これが導出の全部で、あとは微分するだけ：

```
    d log k / dE  =  E_z / X_z  -  4 (E · X) / |X|²
```

第1項が余弦、第2項が距離減衰。**`glassFetch` がその行に来た時点で全部スタックに
載っている**——内積6回、フェッチ増加ゼロ、新しいユニフォームは1つ（スイッチ用）、
ループなし。

### 歩幅は Laplace ではなく Langevin

教科書の一手は `x + Σ·grad`（Laplace）。極限では正しく、反対側では役に立たない：
開口全体を覆う拡散フットプリントは uv で Σ ≈ 1/4、勾配 2 程度は普通なので、
**窓の半分だけ動けと言ってくる**。悪いのは勾配ではなく**モデル**で、楕円の上に
台のある密度の平均が楕円の外に出ることはない。線形の一歩はそれを知らない。

そこで**タップが既に仮定しているプロファイルの方を傾ける**。各軸でフットプリントは
半長 h のスラブ（Day 043 のスラブ重みは円板の周辺分布、スラブ内の読みは ripmap の箱）で、
[-h, h] 上の一様密度を exp(g·x) で傾けた重心には閉形式がある：

```
    <x>  =  h · L(g h),        L(t) = coth t - 1/t
```

**Langevin 関数**。小さい傾きでは Laplace そのもの（L(t)→t/3、一様スラブの分散は
h²/3 なので h²g/3 = σ²g が厳密に出る）、大きい傾きでは ±h に**飽和**する——中心は
フットプリントの端まで滑って、その先へは行かない。**有界性が密度の性質であって、
後から付けたクランプではない**というのが、この形を選んだ理由の全部である。

h は「楕円と同じ分散を持つ一様スラブの半長」：半軸 a は分散 a²/4（Day 044 の規約、
support 項を合わせたときの規約）、一様スラブは h²/3 なので h = a·√3/2。

## 定数 0.5 について（これはチューニングではない、と言えるところまで）

`uTilt = 0.5` であって 1 ではない。導出はスケールごと予言するのに、なぜ半分か。

**予言した変位を、測った変位に対して回帰した**（オラクル＝可視核自身の1次モーメント、
Day 047 が 4.35 を出したのと同じ量）：

```
  slope 0.50      R 0.58      |予言| 19.7 texels     |測定| 13.3
```

向きは3分の2の精度で当たっており、長さが 1.6 倍長い。そしてこの2つは**同じ数字を
2回言っている**：最小二乗の係数は R × スプレッド比 = 0.58/1.6 ≈ 0.36〜0.50 で、
**定数の掃引は2つのハーネスで独立に 0.5 で底を打つ**：

```
  gain      0     0.25    0.5    0.75     1     1.25    1.5      2       3
  遮蔽なし 4.37    3.42    3.15   3.34    3.75    —       —       —       —
  遮蔽あり 5.48    5.13    5.04   5.10    5.24   5.42    5.62    6.04    6.80
```

参照も構成も別、遮蔽物の有無も別の2つのハーネスが、**同じ 0.5 で底を打つ**。

**向きが正しく細部が不完全な予測子は、全力ではなく信頼度で当てる**——ノイズのある
推定量の誤差最小の倍率は 1 ではなく信頼度である、というのは統計の当たり前で、
Day 045 が「測定共分散に一致させることは誤差最小ではない」と記録したのと同じ形の
主張である。値そのものは**測って**決まっており、2つのハーネスが同じ数を返した。

正直に書いておくと、これは**モデルが何を落としているかの値段**でもある。ここに書いた
核は余弦と減衰しか知らず、**桟のことも遮蔽物のことも知らない**。0.58 はその2項が
変位のどれだけを説明できるか、である。

## 作って、測って、載せなかったもの

### (1) 曲率を歩幅の計量に使う — 4.28 → 4.63（負け）

Σ に楕円ではなく**核自身の2階微分**（1/(-d²log k/dx²)、これも閉形式）を使えば
係数 0.5 が導出から出てくるのではないか、という筋。`min(h²/3, 1/nH)` として
測ったら**悪化**し、しかも回帰の R が 0.617 → 0.568 と**下がった**。曲率項は
X_z → 0 で発散するので、**歩幅を一番必要とする擦れた構成でだけ歩幅を殺していた**。

### (2) 中点法（勾配を一歩の真ん中で読む） — 4.28 → 4.28（引き分け）

log k は曲がっているので、始点で読んだ傾きは一歩の遠い端を過大評価する——これは
古典的な過剰ステップの原因で、直し方は中点法。実装は6内積の再評価1回だけで、
**定数が要らない**のが魅力だった。予言の長さは 19.7 → 18.5 texels しか動かず、
全体は 4.28 → 4.28。**係数2の正体は log の曲がりではない**（これが分かったので
上の「信頼度」という説明に落ち着いた）。

### (3) スラブを開口で切る（非対称区間の傾き平均） — 5.48 → 5.98（負け）

Day 044 が**大きさ**について答えた「開口の外に平均するものは無い」を、**中心**に
ついて訊いたもの。[-h,h] の代わりに単位正方形との交差区間 [p,q] を使えば、
傾き平均は**その区間自身の中点＋自身の半幅×Langevin**で、式は1つのまま。
左端に半分はみ出したスラブは、傾きが無くても質量が右にある。

負けた。しかも**回帰が理由を言う**：クリップ単独の予言と測定変位の相関は
**R = 0.083**——**ほぼ無相関**である。Day 044 の「箱は truncation であって shift
ではない」と Day 047 の「開口の切断は中心では負ける（5.91）」が、**3つ目の
まったく違う導出からもう一度再現された**。3回別々に同じ壁に当たったので、
これは今後「窓の縁は中心を動かさない」として扱ってよい。

（tilt + clip も測ってある：5.48。tilt 単独の 5.04 より悪い。既定オフ。）

## 負けている場所（隠さずに）

遮蔽なしの表の**小さい2ビン**で今日は負ける：窓の1/10 で 3.05 → 3.66、
1/10〜1/2 で 3.50 → 3.81。合計 51/1024 構成、5%。

理由は分かっていない。予想としては、フットプリントが小さいところでは真の変位も
小さく（`?pass=21` で近景の板の反射が真っ黒なのはそれ）、**信頼度 0.5 の一律適用が
そこでは大きすぎる**——つまり gain をフットプリント径の関数にすれば取れる可能性が
高い。ただし**それは今日の導出には無い自由度**なので、明日の候補に置く。
理由を言えない改善は載せない、というこのシリーズの規則。
