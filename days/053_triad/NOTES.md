## 何を再現したか — 1つだけ

**「幕が変わる」という1つの出来事。** 背景色・体の輪郭・回転の速度・活字の色が、
別々のアニメーションとしてではなく **1本の連続量 `actPos ∈ [0,2]`** から出てくること。
幕は状態ではない。第1幕と第2幕のあいだには、両方の幕が同時に立っている場所がある。

## 何を捨てたか

- AI生成のアーカイブ画像・映像（サイトの主要な素材。ここでは1枚も使っていない）
- KH Type（実書体。system の grotesque ＋ 特大トラッキングで組みだけ真似た）
- 実際のコピー・スクロール尺・ローディング
- 三人の振付そのもの（原作の踊りは再現していない。再現したのは**体の作り**のほう）

## 分解した装置 — 旋盤の身体（the lathe body）

Schlemmer の Figurine は腕でも脚でもなく、**旋盤で挽いた立体**でできている。
円盤・球・釣鐘・紡錘を1本の縦軸に積んだだけの体で、関節がない。
そこから素直に出てくる結論が1つある：**この体はポーズを持てない。**
持てるのは輪郭 `r(t)`（足元 t=0 → 頭頂 t=1 の半径）だけで、
だから「踊り」は姿勢の変化ではなく、**輪郭そのものの変化**でしか書けない。

実装はそれをそのまま置いた：

```
profile（制御点列）→ 256サンプルの半径列 → DataTexture
    R = 第1幕の半径 / G = 第2幕 / B = 第3幕
頂点が持っているのは (t, 角度) の2つだけ。位置は持っていない。
頂点シェーダ:  r = dot(texture(uRadius, t).rgb, uActW)      ← 幕の重み和
               p = vec3(r·cosθ, t·H, r·sinθ)
法線も同じ関数の差分から作る（形が profile しか持っていないので、
法線も profile からしか作れない）。n2 = normalize(vec2(H, -dr/dt))
```

`uActW` は幕の重み（和は1）。**幕の切り替えは、テクスチャの3チャンネルの重みが
移っていくこと**として実装されていて、途中の 0.5 では体は2つの幕の平均として挽かれる。
CPU は毎フレーム頂点を1つも触らない（3体 × 256リング × 128分割 = 約10万頂点）。

派生して2つ:

- **呼吸** — `r *= 1 + a·sin(3π·t − 1.15·time)`。輪郭に沿って上へ進む波を1本足す。
  ポーズが無い体でも、輪郭が動けば生きて見える。振幅は幕とともに 0.07 → 0.016 と落ちる
- **歳差** — 回転体を縦軸で回しても**何も見えない**（回転体だから当たり前で、
  作ってから気づいた）。そこで Euler order XYZ の性質を使って、先に z 傾け（1.9° /
  −3.2° / −4.1°）、そのあと y で回す。すると傾いた体が縦軸のまわりを歳差する。
  第1幕は三者三様に揺れ、第3幕では傾きが 18% まで正される（諧謔 → 荘重）

## 舞台

置いたのは3枚だけ。ホリゾント（幕の色）／床（手前は幕の暗い側、奥はホリゾントに合流）／
足元の接地楕円。**落とし影は入れていない** — 原作の舞台には影が無く、
影を足した瞬間に舞台が部屋になる。地平線は「床とホリゾントの色が y=0 で一致する」ことで
出しており、線は1本も引いていない。

色は3幕ぶん:

| 幕 | 地 | register | spin | 呼吸 |
|---|---|---|---|---|
| I  | #EBCE43 レモン | SERENE BURLESQUE | 1.00 | 0.070 |
| II | #D28189 ローズ | CEREMONIOUS | 0.34 | 0.030 |
| III| #0C0B0A 黒 | MYSTICAL FANTASTIC | 0.07 | 0.016 |

活字の色も同じ `actPos` から引いていて、第3幕でだけ地と反転する。

## 次に効きそうなこと（daily の宿題ではなく、覚え書き）

- profile を1枚のテクスチャに畳んだので、**幕は3つでなくてもよい**。
  テクスチャの幅を増やせば何幕でも積める（重みを N 次元にするだけ）
- 歳差は「回転体は回しても見えない」への対処だったが、
  もっと素直な手は **profile を θ にもわずかに依存させる**（軸対称を1%だけ崩す）こと。
  そうすると旋盤の体のまま、回転が見える
