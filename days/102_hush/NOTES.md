## キー演出 = 「Eliminate」

サイトは「漏れを消す」と宣言するだけで、**何が消えて何が残るのか**は見せない。今日はそこを装置にした。
何でできているか: **時間（打撃→減衰）＋シェーダ（板の曲げ・空気の圧力）＋音（WebAudio）＋入力（叩く／箱を下ろす）**。

### 装置: 箱は周波数しか聞いていない（the box only hears frequency）

1. **シンバル = モードのリスト**（`rig.js`）。自由板の Chladni の法則 `f = C·(m+2n)²`、C = 85 Hz で (2,0) が 333 Hz。
   (0,0)(1,0) は剛体運動なので除外、m+2n ≤ 13 で 54 モード・333〜14,718 Hz。
   ハンマリングの不揃いを ±3.5% の決定的ジッタで入れる。閉じたハイハットは高域から先に死ぬ: τ = 0.2·(1000/f)^0.4 s。
2. **箱 = 質量則1行**。6 mm アクリル m = 7.1 kg/m²、`TL(f) = 20·log₁₀(m·f) − 47`。
3. 同じリストを3回足す:
   - **音**: 44.1 kHz で 1.1 s のバッファを open / hushed の2本レンダリング（2 ms のノイズクリックがスティック）。**両方を open のピークで正規化**するので、hush は「小さく」聞こえる（正規化で打ち消さない）
   - **真鍮**: 頂点シェーダで w(r,θ) = Σ aₖ·sin((n+½)πρ)·ρ·cos(mθ)·cos(φₖ)。法線は差分で曲げるので、異方性反射（旋盤目＝uv.x 周方向）が波打つ
   - **床**: 箱の外の空気。Σ aₖ·gₖ·cos(kₖr − φₖ)/√r を 4.8万点で。**open だと高域モードが細かい粒の干渉縞になり、hush だと低域の太いうねりがかすかに残るだけ**になる。縞の細かさがそのままスペクトル

数字（`rig.js` から計算、画面右の readout と同じ）:

| | |
|---|---|
| 漏れ（全リングダウンのエネルギー） | **−26.1 dB** |
| 漏れ（2 kHz 以上） | **−41.6 dB** |
| 同じ壁でキック 60 Hz | **−5.6 dB** |
| 2 kHz 以上のモードが持つエネルギーの割合 | 50% |

「Eliminate」は誇張ではなく、**シンバルという楽器の大半が高域でできている**から成り立つ。箱は賢くない。

## 見せ方のための嘘（明記）

- 可聴周波数は 60 fps では見えないので、画面は**順序を保った √f 写像で減速**（visHz = 0.55·√(f/340)）、減衰は ×8 に伸ばしている
- 床の波数は真の k = 2πf/c だが、点の格子が最高次モードを運べるよう **c を ×2.5**
- 板の径方向形状は自由環状板の厳密解ではなく sin((n+½)πρ)·ρ の近似
- 曲げの振幅は誇張（uBend）

## 操作

- どこでもクリック = 叩く（初回クリックで AudioContext を起こし、以後は自動の打撃にも音が付く）
- 「Lower / Lift the box」= 箱の上げ下ろし（以後は手動固定）
- 何もしなければ 2.4 s ごとに打撃、3打ずつ hush / open を交互に
- `?hush=0` / `?hush=1` で固定（preview.png は `?hush=0`）

## つまずき

- 箱を `damp(dt)` で動かしたら swiftshader ではフレームが少なく、時刻は進んでいるのに箱が途中で止まった絵が撮れた → 箱の高さを**コンダクタの時計の関数**にした（6点の過去サンプル平均を smootherstep）
- ドームの球冠を円筒の上縁に合わせ損ねて浮いていた → 半径 2.0 の球冠で rim 半径 1.22 に一致させた
