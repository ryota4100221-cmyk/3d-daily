# Day 092 — The Voice Under the Obvious

再現元: **日暮里ゼミナール** https://nippori.lamm.tokyo/ （アーティスト・起業家インタビューのポッドキャスト）
選定: スワイプファイルDB「深掘り済み=true」× canvas/WebGL × 白地/淡色地 × 参考タグ「タイポグラフィ」で WHERE 絞り込み
→ 直近7日に無い subject=文字 を狙って候補を拾い、SOURCES.md を grep（既出0件）。
サイト本体は今回も実測値（DB）だけを根拠にした。

## 何を再現するか（キー演出を1つ）

FVの **「Under the Obvious」** ——Helvetica 260px・行間75%（195px）・字間−5%（−13px）・W400 を
左揃えで3段に積んだ見出し。75%の行間ではキャップハイト(≈0.72em)が行をほぼ埋めるので、3行が1枚の
「文字の板」になる。これだけを取る。

- 何でできているか: **幾何（文字の板を短冊に分割）＋シェーダ（奥行き＝声の音量）＋カメラ（正投影の回転）＋スクロール（角度）**
- コピーの意味をそのまま装置にした: 「あたりまえ（Obvious）の下にあるもの」＝ポッドキャストなので **声**

## 分解した装置 — 声の奥行き（the voice under the obvious）

1. 見出しを canvas に 220px/em でラスタライズし（Liberation Sans＝Helvetica/Arial 互換メトリクスを `public/` から FontFace で読む）、
   900本の縦の短冊に切る。各短冊のインクの縦ランを1インスタンスの箱にする（InstancedBufferGeometry、1本の draw call）。
2. 箱の**前面は全部 z=0** に揃える。正投影で真正面から見ると、どの短冊も同じ顔なので**文字はただ平らに読める**（＝the obvious）。
3. 箱の**奥行き d = 0.035 + 1.35·loudness(s)** em。s = u·9秒 + 経過時間·0.55。
   loudness は「音節 4.2Hz の山 × 句の切れ目（20%で息継ぎ＝0）× 細かい粒（90Hz）」の包絡。
   s が増えるので声は**右から左へ流れる**（原典のマーキーの向き）。前面は一度も動かない。
4. 壁の色は奥に行くほど墨→紙へ（pow(back, 0.62)）。声が消えていくように奥が地に溶ける。前面は墨 0.055、モノクロのみ。
5. スクロール 0→0.5→1 で カメラを **Face（正面）→ Depth（3/4）→ Plan（ほぼ真上）** に回す（正投影のまま）。
   真上からは、文字の上端がそのまま声の波形のプロットになる。

左下の HUD: TURN = スクロール角 / REC = 左端の短冊が今いる音声時刻 / バー = その瞬間の音量（シェーダと同じ式を JS でも持つ）。

## 何を捨てたか

- 動画・写真（原典は写真が主役の章が続く）、エピソード一覧、ゲスト紹介、色（#486898 / #60C0A8 / #F890C8 のアクセント群）
- 本文の小塚明朝 13px は**サイズと行間125%だけ**借りた（書体は端末のミンチョにフォールバック）
- マーキーそのもの（DOMの流れる文字）は捨てて、**流れる向きだけ**を声の流れに移した
- 実音声。音は鳴らない。loudness は合成の包絡（ハッシュ由来の決定的な関数）で、実在の録音ではない

## 正直に

- 書体は Helvetica ではなく Liberation Sans（メトリクス互換だがグリフの形は Arial 寄り。R や G で差が出るが今回の語には無い）
- 短冊は 900 本、縦は 220px/em のラスタ。正面は拡大すると水平方向に 1/900 幅の段が出る
- 4.2Hz は会話の音節レートの目安値で、計測ではない
- ?p=0〜1 でスクロール位置を固定できる（preview は ?p=0.5）

## つまずき

- 正面（?p=0）の headless 撮影は、成功しても 47KB しかない（平らな黒文字だけなので PNG が小さい）。
  空カンバス 31KB との差が小さく、閾値 150KB のリトライループでは「成功」と判定できない。preview は ?p=0.5（184KB）で撮った。
