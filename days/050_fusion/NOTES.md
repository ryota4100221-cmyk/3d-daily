## 何を再現したか — キー演出を1つに絞る

**「白い紙の上に、液滴が融合した塊が1つだけある」** これだけ。
それが何でできているかを言葉にすると：

- **幾何ではない**（メッシュは板1枚。形はどこにも頂点として存在しない）
- **カメラでもない**（固定。動くのは中身だけ）
- **シェーダ**でできている。距離関数と、そのしきい値

そして「融合して見える」ことは、球の数からも大きさからも出てこない。
**面と面のすきま gap が、しきい値 k を下回ること**から出る。

```
smin(a, b, k) = mix(b, a, h) − k·h·(1−h),   h = clamp(0.5 + 0.5(b−a)/k, 0, 1)
gap = |ci − cj| − ri − rj

  gap ≫ k   離れた2つ。間に何も無い
  0 < gap < k   首（neck）が生える。ここだけが「融合」に見える瞬間
  gap < 0   1つの塊。もう境目は無い
```

**分解した装置の名前: 融合しきい値（fusion threshold）。**
`1` `2` `3` キー（または `?k=0|1|2`）で k = 0.06 / 0.26 / 0.62 を切り替えると、
**同じ7個の球のまま**、7個 → 首でつながった1体 → 境目の無い1つの塊、と3段に化ける。
球は1ミリも動いていない。動いたのはしきい値だけ。右下の HUD が
`k` と「いちばん近い組の gap」と「首の本数」を出し続ける。

k は大きさではなく**距離のものさし**なので、球を太らせても融合は起きない。
近づける（gap を下げる）か、k を上げるかのどちらかしかない。この非対称が今日の芯。

## 作ってみて分かったこと（詰まった順）

1. **窓が緩いと、窓ではなくなる。** 最初 `mix(inner, shell, fresnel)` と書いた。
   fresnel は面の大半で小さいので、**塊の表面がほぼ全部「内側」になった**。
   出てきたのは黒〜グレーのメタボールではなく、オレンジの豆1個。
   `dot(n, -rd)` を 0.62〜0.98 で開く（＝真正面を向いた所にしか開かない）に直して、
   ようやく「黒い塊に色が覗く」になった。**穴の縁が絵を決める。**
2. **振れ幅では首は出ない。** 7個を原点まわりの正弦だけで振っていたが、
   小さくすると常時全部重なって1個の豆（k を何にしても同じ絵）、大きくすると
   群れが2つに割れて画面の中央が空く（＝再現元と別の絵）。
   直したのは振れ幅ではなく**置き方**で、芯を1つ・半径0.62の輪に5つ、と最初から
   「首が出る間隔」に置いた。中心⇄輪の gap は 0.04、輪⇄隣は 0.21。
   そのうえで ±0.2 だけ揺らすと、gap が k を何度もまたぐ。
3. **HUD が初期値のまま焼き付く。** DOMダンプでは `GAP −0.168 / NECKS 12/21` と
   生きているのに、同じ瞬間の `--screenshot` は `GAP +0.000 / NECKS 0/21`（マウント時の
   初期マークアップ）だった。virtual time の下では **text の再ラスタが最後の合成に
   間に合わないことがある**。潰し方は2つ入れた：撮影側に
   `--run-all-compositor-stages-before-draw`、ページ側に不可視のCSSアニメーション
   （opacity 1 → 0.999）でレイヤを毎フレーム汚しておく。
   **ビルド成功≠描画成功の、DOM版。数字を出すガードが数字を嘘つく所だった。**
4. **`Number(null)` は 0。** `?k=` の既定値を `Number(...get('k'))` で書いたら、
   パラメータ無しのとき q=0 が `Number.isInteger` を通り、既定が k=0.06（7個バラバラ）に
   なった1枚を撮ってしまった。null を先に弾く。
5. **影の向きは、サンプル点をずらす向きの逆。** 塊の後ろの面で距離関数を切って影にしたが、
   `+x/−y` にずらしたら影が左上へ出た（光が右下から当たっていることになる）。
